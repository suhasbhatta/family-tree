# Parivara web client

The production React/TypeScript client for the private family archive. It uses React Flow for the interactive family canvas and Firebase for Google authentication and Firestore data.

```bash
npm ci
npm run dev
npm run lint
npm test
npm run build
```

Firebase web values are supplied with uncommitted `VITE_FIREBASE_*` environment variables. See the repository-level README for configuration and deployment details.
